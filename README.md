# まいにちの食卓

GitHub Pagesで動く日本語の夕食献立プランナーです。有料API・外部データベース・外部フォント・外部画像を使用しません。入力内容はサーバーに送信せず、この画面内でのみ利用します。

## 今回の改良

- 自由入力とカテゴリ一覧を併用し、一つの登録リストで追加・解除。
- 鶏・豚・牛の部位、魚種を個別に管理。「鶏もも」「鶏モモ肉」などは同じ部位の正式名に統一。
- 肉・魚・卵・大豆製品が指定されている場合、主菜の主材料との完全一致を必須にする。魚種・部位を別のものに置き換えない。
- 主材料が指定されていない場合は、入力食材を使う主菜を優先。入力なしではおすすめ献立。
- 対応レシピなし、未使用食材、不足食材、未登録の調味料を表示。
- 個別に記述した125種類（主菜70、副菜35、汁物20）のレシピ。材料と量・手順・時間・2人分の表記付き。
- 1〜7日、主菜・副菜・汁物、調理方法やたんぱく源の偏りを抑える選択を維持。

## ファイル

`index.html` → `style.css` と `ingredients.js`、`recipes.js`、`app.js` を同じフォルダーに置きます。パスは相対指定なので、既存のGitHub PagesのURLで利用できます。ビルドと追加ライブラリは不要です。

`ingredients.js` はカテゴリ・表記揺れ、`recipes.js` は料理データ、`app.js` は選択処理と画面操作です。`tests/` は開発時の確認に使うファイルで、サイトからは読み込みません。

## 開発時の起動・確認

このディレクトリで実行します。

```sh
node --test tests/planner.test.js
python3 -m http.server 8010 --bind 127.0.0.1
```

ブラウザーの確認用スクリプトは、開発環境にPlaywrightと `/usr/bin/chromium` がインストールされている場合に、上記サーバーを起動した状態で `node tests/browser.cjs` を実行します。これらはサイトの利用には必要ありません。

## 制限

栄養素の数値計算、在庫の数量管理、アレルギー除外、入力食材の保存は行いません。再読み込みで登録内容は消えます。主食を含まない献立には、ごはん等を別途添えてください。表示時間は1品あたりの目安です。

登録リストは在庫量を保証しません。分量と調味料を各レシピで確認してください。肉の部位が未指定の場合は、部位を選び直す案内を表示します。一覧にある全食材に主菜があるわけではありません。対応料理がない食材は明示します。指定条件が厳しい場合は同じ料理が再登場し、条件に合う主菜がない場合は別の肉や魚で補いません。

調味料に分類しただし・オイスターソース等にも動物由来成分が含まれます。肉魚の一致はアレルギー対応や菜食対応を保証しません。骨・加熱状態・衛生に注意して調理してください。
